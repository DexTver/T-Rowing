# 🚣 T-Rowing — система управления соревнованиями по гребле

[Русский](README.md) · [English](README.en.md)

[![Java 21](https://img.shields.io/badge/Java-21-orange.svg)](https://adoptium.net/)
[![Spring Boot 3.5](https://img.shields.io/badge/Spring%20Boot-3.5-brightgreen.svg)](https://spring.io/projects/spring-boot)

Веб-система для проведения соревнований по гребле на байдарках и каноэ: ведение участников,
формирование протоколов и — главная ценность — **автоматическая жеребьёвка и формирование сеток**
(предварительные → полуфиналы → финалы) по официальной системе отбора.

> Учебный/прикладной проект для конкретной гребной базы. Логика сеток реализована движком,
> который интерпретирует внешние JSON-файлы планов, а не «зашита» в код.

## Возможности

| Роль | Что умеет |
|---|---|
| **Зритель** (без входа) | Список соревнований, страница соревнования в виде стартового протокола (заезды по дням, раскрытие на месте), результаты, фильтры по спортсмену/тренеру/категории/субъекту/школе |
| **Тренер** | Подача и правка своей заявки в окне регистрации: поиск по подстроке, добавление спортсменов, предупреждение по возрасту |
| **Судья** | «Создать соревнование» (многодневное, категории, галочки финалов B/C), закрытие регистрации → жеребьёвка, быстрый ввод результатов, формирование следующих этапов с подтверждением; **импорт стартового протокола из Excel** |
| **Админ** | Управление учётками и мастер-данными, загрузка/валидация JSON-файлов сеток |

## Технологии

- **Java 21**, **Spring Boot 3.5** (Web, Security, Data JPA), **Thymeleaf** + точечный ванильный JS
- **PostgreSQL** + **Flyway** (схема версионируется миграциями)
- **Apache POI** — импорт протоколов Excel
- Сборка **Maven** (есть wrapper), тесты **JUnit 5** (часть — на H2)
- **Docker** / docker-compose

## Архитектура

Два модуля Maven:

- **`seeding-engine`** — чистая логика жеребьёвки и посева сеток, **без БД и веба**. Интерпретирует
  JSON-планы (A–N), валидирует их инварианты, формирует этапы детерминированно (по сохранённому зерну).
- **`app`** — Spring Boot: `web` (контроллеры/Thymeleaf) → `service` (бизнес-логика, конечный автомат
  категории, импорт Excel) → `repository` (JPA) → PostgreSQL. Зависит от `seeding-engine`.

## Быстрый старт (Docker)

```bash
docker compose up --build
```

Приложение: <http://localhost:8080> · начальный вход **admin / admin** (сменить в проде!).

Чтобы увидеть наполненный интерфейс, поднимите с демо-данными (демо-тренер `trainer/trainer`):

```bash
APP_SEED_DEMO=true docker compose up --build
```

## Сборка и тесты (без Docker, нужен JDK 21+)

```bash
./mvnw test               # все тесты (движок + приложение на H2)
./mvnw -pl seeding-engine test   # только движок сеток
```

Приложению для запуска нужен PostgreSQL; параметры — через переменные окружения
(`SPRING_DATASOURCE_URL/USERNAME/PASSWORD`).

## Импорт стартового протокола (Excel)

Судьи привыкли составлять протоколы в Excel со ссылочной структурой: лист **«база»** (картотека:
номер, ФИО, год, разряд, субъект, организация, тренер) и лист протокола, где спортсмен указан
**номером**, а имя подтягивается формулой из базы. Импортёр это понимает: загружает всю базу,
связывает заезды со спортсменами по номеру, восстанавливает дни/категории/этапы.

Синтетический пример формата — [`samples/example-protocol.xlsx`](samples/example-protocol.xlsx)
(реальные данные спортсменов в репозиторий не включены — см. [samples/README.md](samples/README.md)).

## Движок сеток

Каждый план A–N — это JSON-файл (`seeding-engine/src/main/resources/seeding/plan_*.json`), задающий
число предварительных заездов, размеры заездов и **посев** каждого перехода между этапами. Три типа
селекторов покрывают все формулировки первоисточника:

- `place` — «место P заезда H»;
- `best_time` — «лучший по времени среди не прошедших по местам»;
- `place_by_time` — сквозной отбор «X из Y-ых» (для финалов B/C).

Загруженные файлы проходят валидатор (полнота дорожек, баланс «вход = выход», покрытие диапазона
10–135 участников без дыр). Подробнее — в [seeding-engine/README.md](seeding-engine/README.md).

## Структура проекта

```
seeding-engine/   движок жеребьёвки и сеток (чистая логика + планы A–N)
app/              Spring Boot: домен, репозитории, сервисы, контроллеры, шаблоны, миграции
samples/          синтетический пример протокола (без персональных данных)
docker-compose.yml, Dockerfile
```

## Безопасность

- RBAC на сервере (Spring Security), пароли BCrypt, CSRF включён.
- Дефолтные учётки (`admin/admin`) и параметры БД предназначены для локальной разработки —
  **обязательно смените их в проде** (через переменные окружения).

## Статус

Реализованы все функциональные части: движок сеток, публичная часть, тренер, судья (включая импорт
Excel), админка. Развёртывание — базовый `docker-compose`; reverse-proxy/TLS/бэкапы — следующий этап.
