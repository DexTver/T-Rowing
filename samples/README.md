# samples / примеры

⚠️ **Персональные данные сюда не коммитятся.** Реальные стартовые протоколы и картотеки спортсменов
(ФИО, даты рождения, тренеры) исключены из репозитория через `.gitignore`.

В git попадает только синтетический пример:

- **`example-protocol.xlsx`** — пример формата стартового протокола Excel для импорта судьёй.
  Содержит лист **«база»** (картотека: Номер, Фамилия, Имя, год, разряд, субъект, организация, тренер)
  и лист протокола, где спортсмены указаны **номером** из базы. Имена и данные — вымышленные.

Этим файлом можно проверить импорт: «Судейская» → «Импорт стартового протокола (Excel)».

---

⚠️ **No personal data is committed here.** Real start protocols and athlete databases are excluded via
`.gitignore`. Only the synthetic `example-protocol.xlsx` is tracked — use it to try the referee's
Excel import. All names are fictional.
